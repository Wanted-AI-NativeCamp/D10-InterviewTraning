# D10 · 역전 취업 코칭 (AI 모의면접 코치)

신입 지원자를 위한 **AI 모의면접 서비스**예요. Streamlit 화면에 OpenAI API를 붙여 만들었어요.
직군 · 회사 · (선택) 내 경험을 넣으면 면접 5문제(질문마다 꼬리 질문 최대 1개)를 진행하고, 평가 위원 4명이 채점한 뒤 결과 확인 · 재도전까지 이어져요. 기록은 회사 · 직군별 회차로 쌓이고, Markdown 파일 하나로 저장 · 복원해요.

> AI 네이티브 캠프 10일차 실습(`git-practice`)에서 시작해 디벨롭한 프로젝트예요.

## 현재 상태 한눈에 보기 (11/03 기준)

```
시작(닉네임) → 홈
  → 면접 정보 설정 (직군 · 분야 · 회사(선택) · 내 경험(선택) · 출제 방식 3종)
  → 면접관 소개 → 면접 5문제 (질문마다 꼬리 질문 최대 1개, 코드가 횟수 제한)
  → 평가 받기 (위원 4명) → [평가 확인하기] → 그 회차의 평가 기록
  → 재도전 (이전 최고 점수와 비교, 횟수 제한 없음)
  → 데이터 저장하기 (Markdown v2 한 파일) → 다음에 Markdown 복원으로 이어 하기
```

### 화면 구조 (GNB · LNB)

| 위치 | 메뉴 | 하는 일 |
| --- | --- | --- |
| GNB | 홈 | 최근 기록 · 빠른 시작 |
| GNB | 새 면접 시작 | 면접 정보 설정 → 면접 진행 |
| GNB | 면접 코칭 | 면접 데이터 목록 (회사 · 직군별 묶음) → 면접 상세 |
| GNB | 데이터 저장하기 | 모든 회차를 Markdown v2 파일 하나로 다운로드 |
| 면접 상세 LNB ① | 평가 기록 (회차별) | 위원 4명 점수 · 기준별 점수 · 모의 결과 · 역전의 실마리. 평가 전 회차는 "아직 평가 전이에요" 안내와 [평가 받기] |
| 면접 상세 LNB ② | 면접 기록 (전체) | 회차별 면접 기록 표 → 확인할 회차 → 핵심 정보 카드 → 전체 회차 종합 → 맨 아래 전체 면접 대화 기록 (접힘) |
| 면접 상세 LNB ③ | 재도전 (전체) | 점수가 낮은 답을 다시 써서 이전 최고 점수와 비교 |

- 회차 번호는 **회사(없으면 '기타') + 직군**별로 따로 쌓여요. 다른 회사 · 직군 기록과 섞이지 않아요.
- LNB에서 마지막으로 고른 탭과 회차를 기억해서, 홈이나 목록에 다녀와도 그대로 돌아와요.
- 직군별 대표 면접관 1명 (디자인 · 개발 · PO · 마케팅).
- 암기 탭은 MVP1에서 뺐어요 (옛 리포트의 암기 데이터는 지우지 않고 보존).

### 파일 사이의 관계

```
app.py ──▶ coach.py ──▶ prompts.py
  │           │
  │           └──▶ data/*.csv · *.md · *.json
  ├──▶ llm.py ──▶ OpenAI API
  └──▶ error_log.py
```

- **화면(`app.py`)** 은 `coach.py`로 프롬프트를 채우고, `llm.py`의 `ask_json()`으로 AI를 불러요.
- **AI는 판단만** 하고, 점수 합계 · 평균 · 전후 차이 · 질문 개수 · 꼬리 질문 횟수는 **코드(`coach.py`)가 계산**해요.

### `coach.py` 주요 숫자

| 상수 | 값 | 뜻 |
| --- | --- | --- |
| `TOTAL_QUESTIONS` | 5 | 면접 질문 수 (공통 2 + 분야 3) |
| `MAX_FOLLOW_UPS` | 1 | 질문당 꼬리 질문 최대 개수 |
| `CRITERIA` | 4개 | 구체성 · 직무 연관 · 구조 · 근거/검증 (각 0~5점, 답 하나 20점) |
| `PANEL_MAX` | 10 | 위원 점수 상한 (0~10) |
| `REWRITE_BELOW` | 14 | 이 점수 미만인 답만 고친 답을 보여 줌 |
| `PASS_TOTAL` / `PASS_PANEL` | 90 / 9.0 | 합격선 (종합 100점 · 위원 평균) |
| `CANDIDATE_TOTAL` / `CANDIDATE_PANEL` | 70 / 7.0 | 합격 후보선 |
| `MAX_ANSWER_CHARS` | 1500 | 답 한 개 최대 글자 수 |
| `MAX_STORE_ROUNDS` | 500 | Markdown v2 파일 하나의 회차 수 안전 한도 |

### 환경 변수 (`.env`)

| 이름 | 필수 | 설명 |

## 코드를 고칠 때 참고

- 프롬프트 문장은 `prompts.py`에만 있어요. 화면 글은 `app.py`, 숫자 규칙은 `coach.py`.
- OpenAI 호출은 `llm.py` 한 곳뿐이에요. (`OpenAI(` 로 검색하면 한 군데만 나와야 해요)
- 꼬리 질문은 질문당 최대 1개이고, 프롬프트가 아니라 코드가 막아요.
- 지원자가 쓰지 않은 경험 · 숫자는 AI가 지어내지 않고 `[확인 필요: ○○]`로 남겨요.
- 오류 기록에는 답변 전문 · 개인정보 · API 키 · AI 응답 전문을 남기지 않아요.
- 자세한 개발 규칙은 [`d10-interview/CLAUDE.md`](d10-interview/CLAUDE.md), 기획은 [`d10-interview/prd/`](d10-interview/prd/)에 있어요.

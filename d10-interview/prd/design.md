# 역전 취업 코칭 MVP1 통합 개선

기존에 작성한 `design.md`를 참고하여 디자인 시스템을 정리하고, 면접 정보 설정 화면의 직군별 페르소나 및 산업 분야 선택 기능을 개선해 주세요.

## 1. 디자인 시스템 적용

기존 `design.md`의 컬러·타이포그래피·컴포넌트 원칙을 유지하되, 서비스 내부 화면에 맞게 조정합니다.

- 대표 브랜드 컬러: `#0252DE`
- 기본 배경: `#FFFFFF`
- 기본 텍스트: `#0B1020`
- 보조 텍스트: `#444D63`
- 폰트: Pretendard
- 불필요한 그라데이션·그림자·강조 테두리 최소화
- 모든 영역을 카드로 감싸지 않기

### 화면별 기준

- 시작 화면: 기존 브랜드 표현 유지
- 홈: 간결한 정보 위계 유지
- 면접 설정: 선택 요소와 정보 영역의 일관성 강화
- 면접 진행: 질문·답변 중심의 집중형 레이아웃
- 평가 리포트: 평가 결과의 가독성 강화
- 면접 기록: 탐색성과 정보 밀도 우선

### 크기 및 간격

- 랜딩 H1: 48~54px
- 서비스 내부 H1: 24~32px
- 일반 카드 라운드: 16~20px
- 주요 카드 라운드: 20~24px
- 섹션 간격: 화면 특성에 따라 16~48px
- 모바일에서 기존 기능과 입력창 접근성 유지

기존 IA와 화면 이동 구조는 변경하지 않습니다.

## 2. 직군별 페르소나 UI 개선

대상: 개발·디자인·PO·마케팅

현재 직군마다 면접관 소개 방식이 다르므로 공통 구조로 통일합니다.

### 기본 표시
- 면접관 직책 및 경력
- 성격과 질문 성향 요약
- 핵심 평가 역량
- 면접 진행 방식

### 상세 표시
- [면접관 자세히 보기]를 통해 기존 상세 정보 제공
- 기존 페르소나 내용과 AI 지시문 유지
- 정보량만 줄이고 실제 면접관 설정은 변경하지 않음

## 3. 직군별 산업 분야 면접

기존 디자인 직군의 분야별 면접 기능을 개발·PO·마케팅에도 확장합니다.

- 4개 직군 모두 공통 면접 / 분야별 면접 선택 가능
- 분야는 세부 직무나 기술 스택이 아닌 산업 분야를 의미
- 직군별로 적합한 산업 분야 목록 제공
- 산업 분야 선택 시 실제 AI 질문 생성에 해당 산업 맥락 반영
- 기존 디자인 분야 목록은 유지
- 면접관 페르소나와 평가 체계 유지

산업 분야 목록은 기존 논의안을 참고하되, **구현 전 직군별 목록을 먼저 보고해 주세요.** 목록 확정 전에는 임의로 변경하지 마세요.

## 4. 기능 보호 및 검증

- 기존 면접 기록·회차 구조 유지
- Markdown v1/v2 호환성 유지
- 질문 5개 및 조건부 꼬리질문 최대 1개 유지
- 4인 평가 체계 유지
- 기존 API 설정 유지
- 실제 OpenAI API 호출 없이 자동화 테스트
- 데스크톱·모바일 브라우저 검증

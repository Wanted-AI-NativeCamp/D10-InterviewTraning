# 01. 홈

## 목적

사용자가 경험 관리 또는 면접 코칭을 선택하고, 기존 활동을 빠르게
이어간다.

## 기능

  ID        요구사항                                                우선순위
  --------- ------------------------------------------------------- ----------
  HOME-01   첫 방문: \[경험 카드 작성\] / \[면접 시작\] 동등 노출   P0
  HOME-02   기존 사용자: 최근 프로젝트·면접 이어하기                P0
  HOME-03   진행 중 퀘스트·다가오는 면접 요약                       P1
  HOME-04   전략 확인 바로가기                                      P1

## 상태

-   첫 방문: 저장된 경험/면접 없어도 면접 시작 가능.
-   복귀: 마지막 미완료 세션 및 최근 경험 카드.
-   일정 없음: 빈 상태 안내; 허위 D-day 생성 금지.

## 완료 기준

-   경험 카드 없이도 새 면접을 시작할 수 있다.
-   면접 기록 없이도 경험 관리로 이동할 수 있다.
-   저장된 세션을 이어할 수 있다.

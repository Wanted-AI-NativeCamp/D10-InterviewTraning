# 01. 홈

> 기준: PRD v2.3. 1차 MVP는 면접 시작과 Markdown 복원 진입을 다룬다. 경험 관리 · 퀘스트 · 일정 관련 항목은 **[2차 MVP]** 로 표시한다.

## 목적

사용자가 면접을 빠르게 시작하거나 저장한 기록(Markdown)을 불러와 이어가고, (2차 MVP에서) 경험 관리를 선택할 수 있게 한다.

## 기능

  ID        요구사항                                                       단계     우선순위
  --------- -------------------------------------------------------------- -------- ----------
  HOME-01   첫 방문: \[경험 카드 작성\] / \[면접 시작\] 동등 노출          2차      P0
  HOME-02   기존 사용자: 최근 프로젝트·면접 이어하기                       2차      P0
  HOME-03   진행 중 퀘스트·다가오는 면접 요약                              2차      P1
  HOME-04   전략 확인(취업 관리) 바로가기                                  2차      P1
  HOME-05   \[+ 새 면접 시작\] / \[기존 데이터 Markdown 복원\] 진입        1차      P0
  HOME-06   닉네임 자동 생성 · 수정                                        미확정   —

- 1차 MVP의 '이어하기'는 서비스 내부 저장이 아니라 **Markdown 파일 복원**이다 (PRD 5.6). 복원 자체로 새 회차를 만들지 않는다.
- 닉네임 자동 생성과 GNB 도입의 1차 포함 여부는 미확정이다 (PRD 10.2).

## 상태

-   첫 방문: 저장된 경험/면접 없어도 면접 시작 가능.
-   복귀: Markdown 복원 후 기존 회사(또는 '기타') · 직군 · 회차 기록 확인, 기존 회차에서 재도전, 또는 새 면접 시작. (최근 경험 카드 표시는 2차 MVP)
-   복귀: 마지막 미완료 세션으로 돌아가기. (기존 요구사항 — 진행 중 면접의 저장 · 재개 정책이 확정될 때 구현 여부를 결정한다. 현재 구현되어 있지 않으며 1차 확정 기능이 아니다.)
-   일정 없음: 빈 상태 안내; 허위 D-day 생성 금지. [2차 MVP]

## 완료 기준

-   경험 카드 없이도 새 면접을 시작할 수 있다.
-   Markdown 파일(v2 · v1)을 불러와 기존 기록을 이어갈 수 있다.
-   면접 기록 없이도 경험 관리로 이동할 수 있다. [2차 MVP]

# 03. 면접 코칭

## 목적

질문에 맞는 경험을 **답변 전에 비교·선택**하고, 답변을 검증·개선한다.

## 기능 요구사항

  ID       요구사항                                          우선순위
  -------- ------------------------------------------------- ----------
  INT-01   새 면접 / 저장된 세션 이어하기                    P0
  INT-02   회사·직무 선택/등록, 일반 면접 허용               P0
  INT-03   질문별 경험 후보 자동 추천(상위 2\~3개)           P0
  INT-04   경험 2개 자동 비교 / 리스트에서 수동 선택 비교    P0
  INT-05   강조 역량·적합도·준비 상태·추천 이유 비교         P0
  INT-06   경험 선택 또는 경험 없이 답변                     P0
  INT-07   경험 참고/미참고 선택 및 기록                     P0
  INT-08   사이드 패널에서 경험 추가·수정, 답변 draft 보존   P0
  INT-09   5문항 + 질문당 조건부 꼬리질문 최대 1개           P0
  INT-10   AI 답변 평가, 질문별 활용 답변 저장               P0
  INT-11   평가에서 강화 퀘스트 연결                         P0
  INT-12   재도전 및 이전 답변 비교                          P1
  INT-13   면접만/경험+면접 통합 Markdown 내보내기           P0

## 화면 레이아웃(데스크톱)

-   메인: 면접관 질문, 현재 문항, 답변 입력, 제출.
-   오른쪽 접이식 패널: 경험 추천 목록, 2개 비교, 경험 상세/수정.
-   평가: 질문별 점수·근거·퀘스트, 선택 경험과 당시 버전.

## 경험 추천·비교

질문은 미리 분류된 `question_type`과 `required_competencies`를 사용한다.
자동 추천: 적합도 높은 경험 2개를 비교 후보로 설정. 직접 선택: 전체 경험
리스트에서 원하는 2개를 지정. 비교 항목: 1. 질문 유형
적합도(높음/보통/낮음/정보 부족) 2. 강조할 역량 3. 실제 행동·판단
근거·결과 기록 상태 4. 경험 강화·전달 강화 퀘스트 상태 5. **기존 활용
답변 평가가 있을 때만** 해당 점수·조건 표시

**경험 적합도 ≠ 답변 평가 점수.** 기존 평가 없는 경험도 비교 가능.
규칙은 `technical/AI_RULES.md`.

## 경험 참고 설정

-   `reference_used=true/false`를 질문별 답변에 저장.
-   면접 시작 시 기본값 선택 가능; 질문별 변경 허용.
-   미참고 시 카드 내용 숨김. 경험 비교는 답변 전 단계에서 허용하되,
    '미참고'의 의미를 **답변 작성 중 카드 내용을 열람하지 않음**으로
    명확히 정의.
-   참고 여부는 점수 산식에 넣지 않음.

## 면접 중 경험 수정

경험 선택 → 상세 → 수정 → 저장 → 면접 복귀. - 입력 중 답변 및 질문 진행
상태 유지. - 원본 경험 새 버전 생성. - 제출 시 실제 참조한 경험 버전을
답변에 고정. - 이전 완료 평가 변경 금지.

## 질문·평가

-   총 5개 기본 질문.
-   질문당 꼬리질문 0\~1개(필요 시).
-   AI는 답변의 근거·행동·판단·결과를 고정 루브릭으로 분석.
-   질문별 결과 및 최종 리포트.
-   기존 4명 위원 평가는 단일 공통 루브릭 전환을 우선 제안(미확정).
-   AI 실패 시 답변은 먼저 저장하고 평가 대기 처리.

## Markdown 내보내기

-   `EXPOR-02`: 경험+면접 통합 내보내기, 세션 진행 중에도 가능.
-   `EXPOR-03`: 기존 면접 기록만 내보내기 유지(호환).
-   진행 중인 면접의 미응답/미평가 문항은 상태 표시.
-   작성 중인 미제출 답변은 기본 제외하고 포함 여부를 사용자에게 확인.

## 완료 기준

-   추천된 경험 2개 또는 수동 선택한 경험 2개 비교 가능.
-   선택 경험으로 답변 작성·제출 가능.
-   카드 수정 후에도 draft와 질문 위치 유지.
-   참고 여부가 별도 기록되고 평가 점수에 영향 없음.
-   면접 도중 통합 Markdown 다운로드 가능.
-   카드 수정 후 이전 평가가 그대로 유지됨.

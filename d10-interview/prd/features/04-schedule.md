# 04. 취업 관리 (전략 확인) [2차 MVP]

> 기준: PRD v2.3 (5.5 · 6.8). 이 문서 전체가 **2차 MVP** 범위다.  
> 메뉴명은 PRD · IA 의 **취업 관리 (Schedule)** 로 통일한다. (v2.2 이전 이름: '전략 코칭' → '전략 확인')  
> 1차 MVP에 포함되는 것은 회사 · 직군 식별과 회차 연결뿐이다: 회사는 `company_id`(고유 ID) · `company_name`(표시 이름) · `company_key`(앞뒤 공백만 제거한 비교용 키)로 구분하고, 키가 정확히 같으면 같은 회사다. 회사명 변경 UI는 2차다.

## 목적

지원 회사별 면접 준비 정보와 강화 퀘스트를 한눈에 확인한다. 자유 대화형
AI 코칭 화면이 아니다.

## 기능

  ID       요구사항                                       우선순위
  -------- ---------------------------------------------- ----------
  SCH-01   회사명, 설명, 분야, 직무, 지망 태그 등록       P0
  SCH-02   지원 상태(준비/지원/대기/면접/결과) 관리       P0
  SCH-03   지원·면접 일정 및 D-day 표시                   P1
  SCH-04   전체/지원/면접 일정 필터                       P1
  SCH-05   회사별 관련 경험·면접 이력·평가 조회           P1
  SCH-06   경험 강화/전달 강화 퀘스트 조회·상태 관리      P0
  SCH-07   일정 긴급성·지망 순위·미완료 과제 기반 정렬    P1
  SCH-08   회사별 또는 전체 통합 Markdown 내보내기 진입   P1

- 지망 태그는 고정된 1\~3지망이 아니라 사용자가 직접 만드는 태그(1지망, 2지망 등)이며 회사 단위로 설정한다 (PRD 5.5).
- SCH-02 의 지원 상태 단계 `준비 → 지원 → 대기 → 면접 → 결과` 는 **기존 요구사항 후보 — 2차 MVP에서 확정**한다. 확정된 최종 상태 체계가 아니며, 단계별 정의 · 명칭, 상태 변경 방식, 지원 마감일 · 면접일 등 일정 정보(SCH-03)와의 연동 방식은 2차 MVP에서 정한다. 1차 MVP 구현 범위에는 포함하지 않는다.
- 회사를 지정하지 않은 면접 기록은 '기타' 그룹으로 보여 주며(1차), 실제 회사명 '기타'와 구분한다. '기타' 기록을 취업 관리의 회사로 옮기거나 연결하는 기능은 미확정이다.

## 회사별 화면

상단: 회사/직무/지망/상태/D-day. 중단: 연결 경험 카드 및 최근 면접 평가.
하단: 미완료 퀘스트, 추천 다음 행동, 면접 이력.

## 퀘스트 유형

**경험 강화:** 경험 자체의 사실·판단·결과 보완. 완료 시 원본 경험 카드
새 버전. **전달 강화:** 이미 기록된 경험을 실제 답변에서 설명하는 능력
개선. 후속 답변으로 재검증. 상태: 미시작 → 진행 중 → 적용 완료 → 재검증
완료(해당 시).

## 규칙

-   퀘스트는 경험/활용 답변과 연결된 독립 데이터.
-   회사와 무관하게 재사용 가능한 경험 강화 퀘스트는 중복 생성하지
    않도록 연결 관계 확인.
-   회사별로 강조할 역량과 답변 이력은 구분.
-   D-day 우선순위는 단순 추천이며 사용자 직접 조정 가능.
-   퀘스트 완료가 합격 가능성 향상을 보증하지 않음.

## 완료 기준

-   회사별 경험·면접·퀘스트를 한곳에서 확인 가능.
-   퀘스트에서 경험 관리 또는 면접 코칭으로 이동 가능.
-   기존 평가가 경험 카드 수정에 따라 자동 변경되지 않음.

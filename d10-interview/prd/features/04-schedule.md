# 04. 전략 확인

> 이전 메뉴명 '전략 코칭'을 **전략 확인**으로 변경한다.

## 목적

지원 회사별 면접 준비 정보와 강화 퀘스트를 한눈에 확인한다. 자유 대화형
AI 코칭 화면이 아니다.

## 기능

  ID       요구사항                                       우선순위
  -------- ---------------------------------------------- ----------
  SCH-01   회사명, 설명, 분야, 직무, 1\~3지망 등록        P0
  SCH-02   지원 상태(준비/지원/대기/면접/결과) 관리       P0
  SCH-03   지원·면접 일정 및 D-day 표시                   P1
  SCH-04   전체/지원/면접 일정 필터                       P1
  SCH-05   회사별 관련 경험·면접 이력·평가 조회           P1
  SCH-06   경험 강화/전달 강화 퀘스트 조회·상태 관리      P0
  SCH-07   일정 긴급성·지망 순위·미완료 과제 기반 정렬    P1
  SCH-08   회사별 또는 전체 통합 Markdown 내보내기 진입   P1

## 회사별 화면

상단: 회사/직무/지망/상태/D-day. 중단: 연결 경험 카드 및 최근 면접 평가.
하단: 미완료 퀘스트, 추천 다음 행동, 면접 이력.

## 퀘스트 유형

**경험 강화:** 경험 자체의 사실·판단·결과 보완. 완료 시 원본 경험 카드
새 버전. **전달 강화:** 이미 기록된 경험을 실제 답변에서 설명하는 능력
개선. 후속 답변으로 재검증. 상태: 미시작 → 진행 중 → 적용 완료 → 재검증
완료(해당 시).

## 규칙

-   퀘스트는 경험/활용 답변과 연결된 독립 데이터.
-   회사와 무관하게 재사용 가능한 경험 강화 퀘스트는 중복 생성하지
    않도록 연결 관계 확인.
-   회사별로 강조할 역량과 답변 이력은 구분.
-   D-day 우선순위는 단순 추천이며 사용자 직접 조정 가능.
-   퀘스트 완료가 합격 가능성 향상을 보증하지 않음.

## 완료 기준

-   회사별 경험·면접·퀘스트를 한곳에서 확인 가능.
-   퀘스트에서 경험 관리 또는 면접 코칭으로 이동 가능.
-   기존 평가가 경험 카드 수정에 따라 자동 변경되지 않음.

# 수동 회귀 점검표 (P0-05)

`before-mvp1` 면접 기능을 보호하기 위한 점검표예요. C안 작업(P1~P3)마다 바뀐 범위를 이 표로 다시 확인해요.

## 현재 상태 (2026-11-02 · P0 완료 시점)

| 구분 | 상태 | 비고 |
| --- | --- | --- |
| 자동 테스트 | **통과** (80개) | `after-mvp1` · 아래 **자동** 표시 항목의 '값 · 단계 전환' 부분만 해당 |
| 실제 브라우저 수동 점검 | **미실시** | **수동** 표시 항목은 아직 하나도 확인하지 않음 (통과 아님) |
| 실제 AI API 점검 | **미실시** | **API** 표시 항목 · 11장은 별도 승인 전까지 하지 않음 (통과 아님) |

수동 · API 점검을 하면 맨 아래 '실시 기록' 에 날짜 · 브랜치 · 결과를 적어요. 기록이 없는 항목은 확인하지 않은 것이에요.

## 표기

| 표기 | 뜻 |
| --- | --- |
| **자동** | 자동 테스트가 이미 확인 (`python -m unittest discover tests`). 수동으로는 화면에 맞게 보이는지만 훑어봐요 |
| **수동** | 실제 브라우저에서 직접 확인 (자동 테스트로 확인할 수 없거나 아직 자동화하지 않은 것) |
| **API** | 실제 AI 호출이 필요 (별도 승인 후에만 진행) |

## 준비

- 실행: `d10-interview` 폴더에서 `streamlit run app.py` → http://localhost:8501
- 비교 기준: 같은 항목을 `before-mvp1`(변경 전)과 작업 브랜치에서 각각 확인
- 브라우저: Chrome · 창 너비 1280 / 768 / 420 / 360px · 밝은 · 어두운 테마
- v1 파일: `tests/fixtures/v1/supported/*.md` (정상) · `partial/` · `unsupported/` (실패)
- API 없이 할 때: **수동** 항목 중 AI 를 부르지 않는 것만 진행 (AI 를 부르는 버튼은 누르지 않음)
